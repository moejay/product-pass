Support

For help, bug reports, or account and privacy questions:

  • Email product-pass@moejay.dev
  • Open a GitHub issue for reproducible product bugs

Before reporting a problem

  1. Build or install the latest Product Pass release.
  2. Reload the extension and retry on a normal HTTP or HTTPS page.
  3. Include your browser/version, Product Pass version, exact error, and reproduction steps.
  4. Remove API keys, access tokens, private URLs, customer information, and screenshot contents before sharing logs.

Known boundaries

Browser-internal pages, extension stores, PDFs, local files, and cross-origin iframe contents cannot be annotated. Screenshots cover the visible viewport and remain local. AI and GitHub integrations depend on their respective providers.

Delete local data

Use Delete session to remove a session’s notes, drafts, and screenshots. Use Settings to disconnect providers or clear API credentials. Uninstalling the extension removes its extension-managed local data according to browser behavior.
